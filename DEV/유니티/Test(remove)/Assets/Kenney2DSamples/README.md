# Kenney 2D Teaching Samples

This package contains three focused Unity 2D examples:

1. `01_FarmTilemap` — layered Tilemaps, tile assets, collision Tilemap, and top-down movement.
2. `02_SideViewParallax` — repeated background layers, camera-relative parallax, side-view movement, and jumping.
3. `03_Isometric` — isometric Grid/Tilemap, Y sorting, shared-space floors, floor-specific collision, and stair-only elevation changes.

Open `Tools > Kenney 2D Samples > Sample Suite Builder` to curate source assets, rebuild the scenes, or export the unitypackage.

The package intentionally includes only a small teaching subset of each source pack. Original source art under `Assets/Art` is not modified.

## Controls

- Farm: WASD, arrow keys, or gamepad left stick.
- Side view: A/D or arrow keys; Space/gamepad south button to jump.
- Isometric: WASD, arrow keys, or gamepad left stick. Walk into a staircase to change elevation.
