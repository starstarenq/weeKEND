### 2.2 코어 게임 시스템 구현
- [ ] **감정 게이지 (Emotion Gauge) System**
  - [ ] 상단 UI 감정 게이지(행복 ↔ 불행) 실시간 변동 로직 구현 [cite: 1]
  - [ ] 감정 상태에 따른 스테이지 몬스터 스탯/난이도 동적 스케일링 [cite: 1]
- [ ] **오큐시스의 장난 & 코스모의 가호 System**
  - [ ] **오큐시스의 장난**: 2챕터부터 챕터당 5회 부정적 디버프(몬스터 증원, 스탯 버프, 선제 적대 등) 무작위 발동 [cite: 1]
  - [ ] **코스모의 가호**: 1챕터 중반부터 챕터당 3회 이로운 버프 발동 [cite: 1]
  - [ ] 가호와 장난 중복 시 상쇄(무효화) 로직 작성 [cite: 1]
  - [ ] 장난 발동 스테이지 클리어 시 악효과 개수 비례 추가 보상 지급 로직 [cite: 1]
- [ ] **보스전 살려주기/처치 선택 System**
  - [ ] 보스 HP 0 달성 시 처치 / 살려주기 분기 팝업 UI 및 입력 처리 [cite: 1]
  - [ ] 처치 시: 장비 + 재화 드랍 [cite: 1]
  - [ ] 살려주기 시: 버프 또는 특수 무기 확률 지급 [cite: 1]
- [ ] **로그라이크 / 메타 진행 시스템**
  - [ ] **삶의 갈림길**: 스테이지 클리어 후 3종 보상(아이템, 버프, 재화) 선택 시스템 [cite: 1]
  - [ ] **기억의 휴식처**: 체력 회복, 에스페란사/응원의 구슬/주문서 구매 상점 UI 및 기능 [cite: 1]
  - [ ] **다른 시간선**: 회차 종료 후 '기억의 구슬'로 영구 스탯/스킨/아이템 사전구매 저장 기능 [cite: 1]
  - [ ] **루트 기억 & 모르는 기억**: 클리어 루트 표시 및 특수 모드/도전과제 트로피 판정 [cite: 1]
